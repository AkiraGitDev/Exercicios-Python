## 📚 Sobre

Este repositório reúne os exercícios dos três mundos do curso:

- 🌍 **Mundo 1** — fundamentos (variáveis, operadores, entrada e saída, tipos de dado)
- 🌎 **Mundo 2** — controle de fluxo (condições, laços, estruturas de repetição)
- 🌏 **Mundo 3** — estruturas compostas, funções e modularização

## 📁 Estrutura

```text
/Estudos Python   # Exercícios organizados conforme o curso
```

## 🚀 Como rodar um exercício

```bash
# Pré-requisito: Python 3.10+
python "Estudos Python/exercicio_01.py"
```

## 🧠 O que aprendi

- Fundamentos sólidos da linguagem Python
- Lógica de programação aplicada a problemas pequenos
- Manipulação de strings, listas, tuplas e dicionários
- Primeiro contato com funções e modularização
